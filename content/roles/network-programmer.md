# 🌐 네트워크 프로그래머

- English: **Network Programmer**
- 분야: **프로그래밍**

실시간 멀티플레이에서 서버와 클라이언트가 상태를 주고받고 동기화하도록 통신 계층과 네트워크 게임 로직을 구현한다.

## 주로 하는 일

- 서버-클라이언트 통신 구현
- 패킷·프로토콜 설계
- 플레이어와 오브젝트 상태 동기화
- 지연·패킷 손실 대응
- 매칭·세션·Replication 등 멀티플레이 기능 구현

## 필요한 기술·능력·지식

- C/C++·C# 등의 프로그래밍
- TCP/IP·UDP·소켓 프로그래밍
- 서버-클라이언트 구조
- 패킷 및 프로토콜 설계
- 동기화·RPC·Replication
- 지연·패킷 손실·보간·예측 처리
- 멀티스레딩·동시성
- 네트워크 보안 기초

## 알아야 하는 지식 영역

### 네트워크 기초

- TCP/IP 계층과 UDP/TCP 특성
- 소켓과 연결 생명주기
- 직렬화와 패킷 구조
- 대역폭·RTT·Jitter·Packet Loss

### 게임 동기화

- Authoritative Server
- RPC와 Replication
- Snapshot/State Synchronization
- Interpolation·Extrapolation·Client Prediction

### 실시간 문제 해결

- Lag Compensation
- Reconciliation
- Tick Rate와 전송 주기
- 패킷 우선순위와 압축

### 안정성

- 동시성 제어
- 연결 끊김과 재접속
- 비정상 패킷 방어
- 네트워크 로그와 시뮬레이션 테스트

## 대표 산출물

- 패킷 프로토콜
- 동기화 시스템
- 세션/매칭 연동
- 지연 보정
- 네트워크 디버깅 도구
