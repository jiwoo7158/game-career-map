# 🔧 테크니컬 아티스트(TA)

- English: **Technical Artist**
- 분야: **기술 아트**

아트와 프로그래밍의 경계에서 셰이더, VFX, 최적화, 제작 도구와 아트 파이프라인을 연결하고 개선한다.

## 주로 하는 일

- 아트 파이프라인 설계와 자동화
- 셰이더·머티리얼 기술 지원
- 아트 에셋 성능 최적화
- DCC와 엔진 간 데이터 흐름 개선
- 아티스트와 프로그래머 사이 기술 문제 해결

## 필요한 기술·능력·지식

- 3D 아트 제작 과정 이해
- Unity·Unreal
- 셰이더·렌더링 지식
- Python 등 스크립팅
- 아트 파이프라인 자동화
- VFX·재질 시스템
- GPU·메모리 최적화
- 프로그래머와 아티스트 간 기술적 의사소통 능력

## 알아야 하는 지식 영역

### 아트 파이프라인

- DCC→Engine Import 흐름
- Naming/Folder 규칙
- Batch Export/Import
- Asset Validation

### 실시간 그래픽

- Shader Graph/HLSL 기초
- PBR Material
- 텍스처·버텍스·드로우콜 비용
- VFX와 렌더링 순서

### 자동화

- Python 스크립팅
- DCC 툴 API
- 엔진 Editor 확장
- 에셋 검사와 자동 수정

### 기술 조율

- 아트 품질과 성능 예산
- 문제 재현과 프로파일링
- 가이드 문서화
- 아티스트 친화적인 도구 UX

## 대표 산출물

- 아트 파이프라인
- 셰이더/머티리얼 도구
- 에셋 검사기
- 최적화 가이드
- DCC 자동화 스크립트
