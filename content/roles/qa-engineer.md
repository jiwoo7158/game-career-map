# 🧪 QA / QA 엔지니어

- English: **QA / QA Engineer**
- 분야: **품질**

게임의 기능과 품질을 검증하고 버그를 재현·분류하며 반복 가능한 테스트 체계와 자동화를 만든다.

## 주로 하는 일

- 테스트 계획과 케이스 작성
- 버그 발견·재현·우선순위 분류
- 정확한 버그 리포트 작성
- 회귀 테스트
- 테스트 자동화와 로그 분석

## 필요한 기술·능력·지식

- 테스트 케이스 설계
- 버그 발견·재현·분류 능력
- 정확한 버그 리포트 작성
- 게임 시스템 분석
- Python 등 스크립트를 활용한 테스트 자동화
- 로그 분석
- Git·Jira 등의 협업 도구
- 소프트웨어 테스트 방법론

## 알아야 하는 지식 영역

### 테스트 설계

- 기능 테스트
- 경계값·예외 케이스
- 회귀 테스트
- 탐색적 테스트

### 버그 관리

- 재현 절차
- Expected/Actual
- Severity/Priority
- 환경·로그·영상 증거

### 자동화

- Python 스크립트
- 테스트 데이터 생성
- Smoke Test
- Build별 반복 검증

### 분석

- 로그와 Crash Dump 기초
- 네트워크/성능 문제 재현
- 결함 패턴 분류
- 개발 직군과 재현 조건 공유

## 대표 산출물

- 테스트 케이스
- 버그 리포트
- 회귀 테스트 세트
- 자동화 스크립트
- 품질 리포트
