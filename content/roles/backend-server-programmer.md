# ☁️ 백엔드/서버 프로그래머

- English: **Backend / Server Programmer**
- 분야: **프로그래밍**

계정, 데이터 저장, 랭킹, 친구, 길드, 상점 등 지속성 있는 온라인 게임 서비스를 제공하는 서버 시스템을 개발한다.

## 주로 하는 일

- 계정·인증·유저 데이터 서버 개발
- DB 저장·조회와 트랜잭션 처리
- 랭킹·친구·길드·상점 API 개발
- 서버 확장성과 장애 대응
- 운영 로그·보안·클라우드 환경 관리

## 필요한 기술·능력·지식

- C++·C#·Java·Go 등의 서버 프로그래밍
- TCP/IP·HTTP·WebSocket
- 데이터베이스·SQL·Redis
- 서버 아키텍처
- 멀티스레딩·비동기 프로그래밍
- 동시성·트랜잭션
- REST API
- 인증·보안
- AWS/GCP 등 클라우드 환경

## 알아야 하는 지식 영역

### 서버 프로그래밍

- Request/Response와 연결 관리
- 비동기 I/O
- Thread Pool/Event Loop
- 에러 처리와 Timeout

### 데이터

- 관계형 DB와 SQL
- Index와 Query 비용
- Transaction/Isolation
- Redis Cache

### 서비스 기능

- 계정·인증
- 랭킹·친구·길드
- 상점·우편·보상
- REST/WebSocket API

### 운영과 확장

- Stateless/Stateful 구조
- Load Balancing
- 로그·모니터링
- 보안·클라우드·장애 복구

## 대표 산출물

- 계정/인증 서버
- 게임 서비스 API
- DB Schema
- 랭킹/길드/상점 시스템
- 운영 로그/모니터링
