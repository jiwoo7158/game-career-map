# 🛠️ 툴 프로그래머

- English: **Tools Programmer**
- 분야: **프로그래밍**

기획자·아티스트·프로그래머가 더 빠르고 안전하게 콘텐츠를 제작하도록 에디터와 자동화 도구를 만든다.

## 주로 하는 일

- 레벨·데이터·콘텐츠 편집 도구 개발
- Unity/Unreal 에디터 확장
- 반복 작업 자동화
- 데이터 검증 도구 제작
- 사용자 직군의 작업 흐름 개선

## 필요한 기술·능력·지식

- C#·C++·Python 등의 프로그래밍
- Unity/Unreal Editor 확장
- GUI 제작
- 데이터 직렬화
- 파일 처리
- 에디터·자동화 도구 개발
- UX에 대한 기본 이해
- 아티스트·기획자의 작업 과정에 대한 이해

## 알아야 하는 지식 영역

### 에디터 개발

- Editor Window/Inspector 확장
- Unreal Editor Utility/Slate 계열
- Undo/Redo와 선택 상태
- Drag & Drop과 Asset Browser 연동

### 데이터 도구

- JSON/CSV/ScriptableObject/DataAsset
- Serialization과 Migration
- Validation과 오류 표시
- 대량 편집과 검색

### 자동화

- Python·Shell 기반 파이프라인
- Import/Export 자동화
- 배치 처리
- 콘텐츠 검사와 리포트

### 도구 UX

- 작업 단계 최소화
- 실수 방지 설계
- 진행률·로그·오류 피드백
- 비개발자 사용자와 요구사항 정리

## 대표 산출물
