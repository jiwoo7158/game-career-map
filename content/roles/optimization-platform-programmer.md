# 🚀 최적화/플랫폼 프로그래머

- English: **Optimization / Platform Programmer**
- 분야: **프로그래밍**

CPU·GPU·메모리 병목을 분석하고 PC·콘솔·모바일 등 목표 플랫폼에서 안정적인 성능을 확보한다.

## 주로 하는 일

- CPU/GPU 병목 프로파일링
- 메모리 사용량 분석과 최적화
- 플랫폼별 성능·호환성 문제 해결
- 로딩·프레임 시간 개선
- 성능 회귀 감시와 기준 관리

## 필요한 기술·능력·지식

- CPU·GPU·메모리 구조 이해
- 프로파일링 능력
- 멀티스레딩
- 메모리 관리
- 렌더링 최적화
- 알고리즘 최적화
- 플랫폼별 API 및 하드웨어 이해
- Unity Profiler·Unreal Insights·RenderDoc 등의 분석 도구 활용

## 알아야 하는 지식 영역

### 성능 모델

- Frame Time Budget

- 캐시와 메모리 접근 패턴
- GC와 할당 비용

### 프로파일링

- Unity Profiler
- Unreal Insights
- RenderDoc/GPU Profiler
- 트레이스·샘플링·계측

### 플랫폼

- PC/모바일/콘솔 하드웨어 차이
- 스레드와 코어 구성
- 그래픽 기능 수준
- 파일·스토리지·입출력 특성

### 최적화 방법

- LOD/Culling/Batching
- 비동기 로딩

- 성능 회귀 테스트
