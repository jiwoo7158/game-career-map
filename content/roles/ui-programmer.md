# 🧩 UI 프로그래머

- English: **UI Programmer**
- 분야: **프로그래밍**

메뉴, HUD, 인벤토리, 상점, 설정 등 사용자 인터페이스가 게임 데이터와 입력에 맞게 동작하도록 구현한다.

## 주로 하는 일

- HUD·메뉴·인벤토리 등 UI 기능 구현
- 게임 데이터와 UI 상태 연결
- 키보드·패드·터치 입력 처리
- 화면 전환과 UI 애니메이션
- 해상도·플랫폼 대응

## 필요한 기술·능력·지식

- C++/C# 프로그래밍
- Unity UI·UI Toolkit·Unreal UMG/Slate 등의 UI 시스템
- 이벤트 기반 프로그래밍
- MVC/MVVM 등의 UI 구조
- 데이터 바인딩
- 애니메이션·입력 처리
- 다양한 해상도·플랫폼 대응

## 알아야 하는 지식 영역

### UI 구조

- MVC/MVVM 개념
- View와 게임 상태 분리
- 이벤트와 데이터 바인딩
- 화면 스택과 내비게이션

### 엔진 UI

- Unity UI/uGUI와 UI Toolkit
- Unreal UMG/Slate
- 레이아웃·Anchor·Responsive UI
- UI 애니메이션

### 입력과 접근성

- 마우스·키보드·게임패드·터치
- 포커스와 내비게이션
- 키 리바인딩과 설정 반영
- 가독성과 상태 피드백

### 성능

- UI Rebuild 비용
- 리스트 가상화
- 텍스처·폰트 관리
- 잦은 데이터 갱신 최적화

## 대표 산출물

- HUD
- 메뉴 시스템
- 인벤토리 UI
- 상점/설정 UI
- UI 내비게이션 구조
