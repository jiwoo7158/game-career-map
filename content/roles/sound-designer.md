# 🔊 사운드 디자이너

- English: **Sound Designer**
- 분야: **오디오**

효과음, 환경음, UI 사운드를 제작하고 게임 상태에 맞게 재생되도록 오디오 시스템에 적용한다.

## 주로 하는 일

- 효과음 녹음·편집·합성
- 환경음과 공간감 설계
- UI·전투 사운드 제작
- Wwise/FMOD 또는 엔진 오디오 적용
- 상황별 동적 사운드 구성

## 필요한 기술·능력·지식

- 효과음 녹음·편집·합성
- Audition·Pro Tools·Reaper 등의 DAW
- Wwise·FMOD 같은 오디오 미들웨어
- 공간 음향·3D Audio 이해
- 게임 상황에 따른 동적 사운드 설계
- Unity/Unreal 오디오 시스템

## 알아야 하는 지식 영역

### 오디오 제작

- Recording
- Editing/Cleanup
- Layering과 Synthesis
- Loudness와 Dynamic Range

### 게임 오디오

- One-shot/Loop
- Randomization
- Parameter 기반 변화
- Audio Event 구조

### 공간 음향

- Attenuation
- 3D Positioning
- Occlusion/Obstruction
- Reverb Zone

### 미들웨어 연동

- Wwise/FMOD Event
- State/Switch
- RTPC/Parameter
- 엔진 Trigger와 프로파일링

## 대표 산출물

- 전투 SFX
- 환경음
- UI 사운드
- 오디오 이벤트
- 공간 음향 설정
