# 📖 내러티브 디자이너 / 라이터

- English: **Narrative Designer / Writer**
- 분야: **디자인**

세계관, 캐릭터, 퀘스트, 대사와 분기 구조를 설계하고 이야기와 게임플레이가 자연스럽게 연결되도록 구성한다.

## 주로 하는 일

- 세계관과 캐릭터 설정
- 퀘스트와 분기 구조 설계
- 대사와 서사 텍스트 작성
- 플레이어 선택과 결과 연결
- 기획·레벨·게임플레이 시스템과 이야기 통합

## 필요한 기술·능력·지식

- 스토리 구조와 캐릭터 설계
- 대사 작성
- 세계관 구축
- 퀘스트 및 분기 구조 설계
- 플레이어 선택과 게임 시스템을 고려한 서사 설계
- 시나리오 작성 도구 활용
- 게임 플레이와 이야기의 연결 능력

## 알아야 하는 지식 영역

### 서사 구조

- 갈등과 목표
- 캐릭터 Arc
- 장면과 Beat
- 정보 공개 순서

### 인터랙티브 서사

- 분기와 조건
- Choice/Consequence
- 퀘스트 상태
- 플레이어 행위와 서사 반응

### 게임 텍스트

- 대사
- 아이템/퀘스트 설명
- 환경 서사
- UI 텍스트와 맥락

### 구현 연계

- Narrative Tool
- Localization 고려
- 퀘스트 데이터 구조
- 레벨·시스템과 Trigger 연결

## 대표 산출물

- 세계관 문서
- 퀘스트 구조
- 대사 스크립트
- 분기 플로우
- 내러티브 데이터
