# ✨ VFX 아티스트

- English: **VFX Artist**
- 분야: **아트**

폭발, 마법, 총격, 불, 연기 등 플레이의 반응성과 분위기를 강화하는 실시간 시각 효과를 제작한다.

## 주로 하는 일

- 전투·환경·UI 시각 효과 제작
- 파티클·메시·Flipbook 조합
- 셰이더·머티리얼 기반 효과 제작
- 타이밍과 가독성 조정
- GPU 비용을 고려한 효과 최적화

## 필요한 기술·능력·지식

- Unity Particle System·VFX Graph·Unreal Niagara
- 셰이더·머티리얼 기초
- Photoshop·After Effects·Houdini 등의 도구
- 애니메이션·타이밍·색채 감각
- Flipbook·Particle·Mesh Effect 제작
- GPU 성능 최적화

## 알아야 하는 지식 영역

### 실시간 이펙트

- Particle System/Niagara/VFX Graph
- Emitter와 Module
- Mesh Particle
- Trail/Beam

### 리소스 제작

- Flipbook
- Mask/Noise Texture
- Distortion
- 간단한 Procedural Texture

### 표현 설계

- 타격감과 Timing
- 색과 밝기 계층
- 전투 가독성
- 카메라와 화면 점유율

### 최적화

- Overdraw
- Particle Count
- Shader Complexity
- LOD와 거리 기반 비활성화

## 대표 산출물

- 전투 VFX
- 환경 VFX
- 파티클 프리셋
- Flipbook 리소스
- 최적화된 효과 세트
