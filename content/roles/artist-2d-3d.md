# 🎨 3D/2D 아티스트

- English: **3D / 2D Artist**
- 분야: **아트**

캐릭터, 배경, 오브젝트, 텍스처, 스프라이트 등 게임 화면을 구성하는 시각 자산을 제작한다.

## 주로 하는 일

- 캐릭터·환경·오브젝트 제작
- 텍스처·UV·머티리얼 제작
- 2D 스프라이트와 UI용 그래픽 제작
- 게임 엔진에 에셋 적용
- LOD·폴리곤·텍스처 예산에 맞춘 최적화

## 필요한 기술·능력·지식

- Blender·Maya·3ds Max·Photoshop 등의 제작 도구
- 모델링·텍스처링·UV·라이팅 기초
- 형태·색채·구도에 대한 미술 지식
- 게임용 에셋 최적화
- LOD·폴리곤·텍스처 관리
- Unity/Unreal 에셋 적용 과정 이해

## 알아야 하는 지식 영역

### 조형과 시각 기초

- 형태·비례·실루엣
- 색채와 명암
- 구도와 시선 유도
- 스타일 일관성

### 3D 제작

- 모델링과 Topology
- UV Unwrap
- Baking과 Texture Set
- PBR Material

### 2D 제작

- Raster/Vector 자산
- Sprite Sheet
- 해상도와 픽셀 밀도
- 레이어와 Export 규칙

### 실시간 최적화

- Polygon Budget
- LOD
- Texture Resolution/Compression
- 엔진 Import 설정과 머티리얼 구성

## 대표 산출물

- 캐릭터/환경 모델
- 텍스처
- 스프라이트
- 게임용 머티리얼
- 최적화된 에셋
