# ⚙️ 엔진 프로그래머

- English: **Engine Programmer**
- 분야: **프로그래밍**

렌더링, 물리, 메모리, 파일, 리소스 등 게임을 구동하는 핵심 엔진 시스템과 공통 기반을 개발한다.

## 주로 하는 일

- 엔진 코어 시스템 설계
- 메모리·리소스 관리
- 파일·입출력·직렬화 기반 구현
- 멀티스레딩과 작업 시스템 개발
- 렌더링·물리 등 하위 시스템 통합

## 필요한 기술·능력·지식

- C/C++ 고급 활용
- 자료구조·알고리즘
- 메모리 관리
- 멀티스레딩
- 운영체제·컴퓨터 구조
- 파일 시스템
- 물리·렌더링·리소스 시스템 구조
- 엔진 아키텍처 및 대규모 코드 설계 능력

## 알아야 하는 지식 영역

### 저수준 기반

- 메모리 레이아웃·할당기
- 캐시와 데이터 지향 설계
- 스레드·락·Job System
- OS API와 파일 I/O

### 엔진 구조

- Game Loop
- Entity/Component 구조
- 리소스 수명주기
- Serialization과 Asset Pipeline

### 핵심 시스템

- 렌더링 시스템 경계
- 물리 엔진 통합
- 입력·오디오·파일 시스템
- 플랫폼 추상화

### 대규모 소프트웨어

- 모듈 경계와 의존성
- 빌드 시간과 컴파일 구조
- ABI/API 안정성
- 프로파일링과 진단 시스템

## 대표 산출물

- 엔진 코어
- 리소스 시스템
- 메모리 시스템
- Job System
- 플랫폼 추상화 계층
