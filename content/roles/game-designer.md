# 🗺️ 게임 디자이너 / 기획자

- English: **Game Designer**
- 분야: **디자인**

게임의 규칙, 시스템, 성장, 보상과 플레이 흐름을 설계하고 이를 개발 가능한 형태로 구조화한다.

## 주로 하는 일

- 게임 규칙과 시스템 설계
- 성장·보상·경제 구조 설계
- 기능 명세와 데이터 정의
- 프로토타입과 플레이테스트
- 개발 직군과 요구사항 조율

## 필요한 기술·능력·지식

- 게임 시스템 설계
- 규칙·보상·성장 구조 설계
- 게임 분석 능력
- 문서 작성 및 데이터 정리
- 플레이어 경험 분석
- 논리적인 시스템 구조화
- Unity/Unreal 등 엔진의 기본적인 사용 능력
- 개발 직군과의 커뮤니케이션

### 명세와 데이터

- 피드백을 설계 변경으로 연결
