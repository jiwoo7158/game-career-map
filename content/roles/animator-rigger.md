# 🦴 애니메이터 / 리거

- English: **Animator / Rigger**
- 분야: **아트**

캐릭터 뼈대와 스키닝을 구성하고 이동·전투·표현 모션을 제작해 엔진의 애니메이션 시스템과 연결한다.

## 주로 하는 일

- Rig와 Skinning 제작
- 이동·전투·감정 모션 제작
- IK/FK 및 제약 구성
- 모션 캡처 정리와 리타깃
- 엔진 애니메이션 상태 구성 지원

## 필요한 기술·능력·지식

- Blender·Maya 등의 애니메이션 도구
- 인체 움직임과 타이밍 이해
- Keyframe Animation
- Rigging·Skinning
- IK/FK
- Animation Blend·State Machine 이해
- 모션 캡처 수정 및 리타깃
- 게임 엔진 애니메이션 시스템

## 알아야 하는 지식 영역

### 움직임 원리

- Pose와 Silhouette
- Timing/Spacing
- 무게 중심과 관성
- Anticipation과 Follow-through

### 리깅

- Joint Hierarchy
- Skin Weight
- IK/FK
- Constraint와 Control Rig

### 게임 애니메이션

- Animation Clip
- Blend Tree/Blend Space
- State Machine
- Root Motion과 In-place

### 파이프라인

- Retargeting
- Mocap Cleanup
- Animation Event
- 프로그래머·전투 디자이너와 타이밍 조율

## 대표 산출물

- 캐릭터 Rig
- 이동/전투 애니메이션
- 리타깃 세트
- Animation State 자료
- 모션 수정본
