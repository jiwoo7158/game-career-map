# 🖥️ 그래픽스/렌더링 프로그래머

- English: **Graphics / Rendering Programmer**
- 분야: **프로그래밍**

GPU와 그래픽 API를 활용해 화면을 그리는 렌더링 파이프라인, 셰이더, 조명과 시각 품질 기술을 개발한다.

## 주로 하는 일

- 렌더링 파이프라인 구현·개선
- 셰이더와 머티리얼 기능 개발
- 조명·그림자·후처리 기술 구현
- GPU 병목 분석
- 그래픽 품질과 성능의 균형 조정

## 필요한 기술·능력·지식

- C/C++
- 선형대수·벡터·행렬
- 3D 그래픽스 파이프라인
- DirectX·Vulkan·OpenGL 등의 그래픽 API
- HLSL·GLSL 셰이더
- PBR·조명·그림자
- GPU 구조와 병렬 처리
- 렌더링 성능 분석 및 최적화

## 알아야 하는 지식 영역

### 수학과 파이프라인

- 벡터·행렬·좌표계 변환
- Rasterization 파이프라인
- 카메라와 Projection
- Depth·Stencil·Blend

### 셰이딩

- Vertex/Pixel/Compute Shader
- PBR과 BRDF 기초
- 텍스처 샘플링과 필터링
- Normal/Shadow Mapping

### 렌더링 기술

- Forward/Deferred Rendering
- Post Processing
- LOD·Occlusion·Culling
- 실시간 조명과 그림자

### GPU 최적화

- Draw Call과 Batch
- GPU 파이프라인 병목
- 메모리 대역폭과 텍스처 비용
- RenderDoc 등 GPU 캡처 분석

## 대표 산출물

- 렌더링 기능
- 셰이더 라이브러리
- 조명/그림자 시스템
- 후처리 효과
- GPU 최적화
