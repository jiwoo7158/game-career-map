# 🎮 게임플레이 프로그래머

- English: **Gameplay Programmer**
- 분야: **프로그래밍**

캐릭터 이동, 전투, 스킬, 아이템, 상호작용 등 플레이어가 직접 경험하는 게임 규칙과 기능을 구현한다.

## 주로 하는 일

- 캐릭터 컨트롤과 상태 처리
- 전투·스킬·아이템·상호작용 시스템 구현
- 애니메이션·물리·UI 등 다른 시스템과 게임 로직 연결
- 기획 요구사항을 실제 플레이 가능한 기능으로 변환
- 게임플레이 버그 분석과 디버깅

## 필요한 기술·능력·지식

- C++/C# 등 프로그래밍 능력
- Unity·Unreal 사용 능력
- 객체지향 설계
- 자료구조·알고리즘 기초
- 캐릭터 컨트롤·전투·스킬·인벤토리 같은 게임 시스템 구현 능력
- 물리·애니메이션 시스템 활용
- 디버깅 능력

## 알아야 하는 지식 영역

### 프로그래밍 기반

- 객체지향 설계와 컴포넌트 구조
- 자료구조와 알고리즘의 게임 로직 적용
- 이벤트·상태·메시지 기반 구조
- 디버깅과 로그 설계

### 게임 시스템

- 캐릭터 이동과 입력 처리
- 전투·피격·판정·쿨다운
- 스킬·아이템·인벤토리
- 상호작용과 상태 머신

### 엔진 연동

- Unity MonoBehaviour/ScriptableObject 또는 Unreal Actor/Component 구조
- 물리 엔진과 충돌 처리
- 애니메이션 상태 및 이벤트 연동
- 프리팹·블루프린트·데이터 에셋 활용

### 품질과 확장성

- 기능 간 결합도 관리
- 데이터 주도 설계
- 세이브/로드와 상태 일관성
- 프로파일링을 통한 병목 확인

## 대표 산출물

- 캐릭터 컨트롤러
- 전투 시스템
- 스킬 시스템
- 아이템/인벤토리 시스템
- 상호작용 시스템
