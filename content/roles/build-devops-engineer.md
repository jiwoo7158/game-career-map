# 🔨 Build / DevOps 엔지니어

- English: **Build / DevOps Engineer**
- 분야: **인프라**

코드와 콘텐츠를 안정적으로 빌드·테스트·배포할 수 있도록 CI/CD, 자동 빌드, 개발 서버와 인프라를 구성한다.

## 주로 하는 일

- 자동 빌드 파이프라인 구축
- CI/CD 구성
- 빌드 아티팩트와 버전 관리
- 개발·테스트 서버 운영
- 배포 자동화와 빌드 실패 분석

## 필요한 기술·능력·지식

- Git 등 버전 관리
- CI/CD
- Jenkins·GitHub Actions 등의 자동화 도구
- Python·Shell·PowerShell 스크립팅
- Linux·Windows 환경
- Docker 등 컨테이너 기술
- 자동 빌드·배포
- 개발 서버 및 클라우드 인프라 관리

## 알아야 하는 지식 영역

### 버전과 빌드

- Git Branch/Tag
- Build Configuration
- Artifact Versioning
- Reproducible Build

### CI/CD

- Pipeline Stage
- Build/Test/Package
- Cache
- Secret 관리

### 자동화

- Shell/PowerShell/Python
- Jenkins/GitHub Actions
- Notification
- 실패 로그 수집

### 인프라

- Linux/Windows 서버
- Docker
- Cloud VM/Storage
- 배포·롤백과 권한 관리

## 대표 산출물

- CI/CD Pipeline
- 자동 빌드
- 배포 스크립트
- 개발 서버 환경
- 빌드 모니터링
